Outdoor activities (Recreation)

Learn basic outdoor survival skills.

Topic Description

Outdoor survival skills are useful for anyone who likes hiking, camping, or spending time outside. Sometimes things do not go as planned. A person can get lost, run out of water, get cold, or need to make a fire. Knowing some basic survival skills can help in situations like these. It is useful to know these skills before going outdoors.

There are already websites that give information about outdoor safety. The National Park Service and American Red Cross have a lot of useful survival information. They explain skills like finding water, building shelter, making a fire, and getting help. However, the information is often listed with many other safety topics, very limited or spread across different pages. This can make it harder to quickly find one specific skill.

This web app will organize the skills into simple categories such as fire, shelter, water, and navigation. The user will first choose a category and then choose a specific skill. Each skill will have a clear picture or diagram to help show what it looks like. For example, users can see how different fire types are built or what different shelters look like. The page will also explain when the skill can be useful, what items are needed, how it works, and important safety information. This will make the skills easier to understand and remember.

Application Description

Home: Introduces the website and the outdoor survival topic. It will include a short description of the app, some images, and links to the other pages.

Explorer: Users choose a category and then a sub-category. Detailed description of this page is below.

Basics: This page will give general information about outdoor safety and preparation. It may include things like what to bring, how to prepare before a trip, and basic safety tips.

Contact Us: Users can later send their name, email, topic, and message. It can be used for questions, suggestions, or feedback.
